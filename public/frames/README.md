# Wedding Photo Frames

Add your wedding frame PNG files here:

- `wedding-frame-1.png` - Elegant border frame
- `wedding-frame-2.png` - Floral decorative frame  
- `wedding-frame-3.png` - Classic ornate frame

## Frame Requirements

- **Format**: PNG with transparent background
- **Size**: 1080x1080px or higher
- **Style**: Decorative borders that don't obstruct the center area
- **Transparency**: Use alpha channel for frame overlay effect

## Usage

Frames will overlay on the camera preview and be applied to captured photos before background selection.
